## 消费端架构纪律（强制遵照执行）

Iced 表面严格作为纯被动消费端，必须遵照执行自底向上裁决铁律：
- 严禁在 Iced 状态、消息、更新流程或视图中就地修补底层架构未决问题；
- 严禁在 UI 表面自行推导业务事实（如通过比对 ID 猜测活动状态、使用临时布尔标志模拟未裁决的生命周期阶段）；
- 遇底层能力缺失、契约模糊或状态不全时，必须立即暂停上层开发，等待底层 Core 与契约收口完成后再行接入，不得留下空实现或临时垫片。
