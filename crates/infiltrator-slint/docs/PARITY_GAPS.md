# Slint 表面业务认证缺口

> 层级：L3

本文件是 Slint 表面在共享业务目录（`scripts/parity/cross_surface_manifest.tsv` 的
`slint` 行）上的逐格归类与注册表镜像。取证口径与共享契约一致：只有当表面**真的打开了
业务**、像素**真的发生变化**、且该变化大于表面自身的 run-to-run 噪声时，这一格才算
认证通过；`ready` 与像素回执只能由验收批次给出。

## 归类口径

- **implemented**：表面已有承载页（专属页或工作台页）、真实手势与 scenario/contract
  锚点，`FeatureSpec::slint_page` 已登记载体页面；像素回执由验收统一采集后置为 `ready`。
- **pending**：表面尚不承载该业务，或该格的取证需要外部环境；理由必须如实描述缺什么，
  不得用代码级证据冒充像素证据。

## 承载现状

- 已实现并锚定：59 格（下表）——专属承载页覆盖 DNS、诊断、同步、过滤聚合、
  编辑器族与应用路由六个页面；其余业务由产品页与工作台页承载。
- 仍为 pending：1 格（文末）——`shell-keyboard-focus` 的焦点环像素证据需要一台
  能驱动真实指针或按键的取景台架，Slint 取景路径只驱动产品回调，该格诚实保持 pending，
  `FeatureSpec::slint_page` 对应留空。
