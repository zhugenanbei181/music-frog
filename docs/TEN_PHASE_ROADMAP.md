本台账记录 Infiltrator 对标业界成熟客户端（Clash Verge Rev、Clash Party、Flclash、ClashMi）的全景差距与 10 个演进阶段、100 项具体工程落地任务。

## 架构原则与边界约束

1. **求同存异**：
   - **求同**：所有核心控制面（CoreApplication、配置 AST 引擎、订阅清洗 Pipeline、诊断流控、WebDAV 同步）100% 下沉在 Rust 共享层，各前端（Iced 桌面、Bevy UI、Android 原生、CLI）统一消费，零重复造轮子。
   - **存异**：各宿主平台（Windows Service / WinTun、Linux polkit / setcap、macOS launchd / networksetup、Android VpnService）通过标准 `HostAdapter` 契约特化承接。
2. **提高复用率**：
   - 视图层保持为纯渲染投影，业务逻辑与异步操作统一由底层状态机与 Controller 管理。
   - Design Tokens（`theme.rs`）与公共组件库（`components.rs`）最大化复用，严禁各页面私自分叉样式。
3. **严格按序推进与质量门禁**：
   - 严格按 Phase 01 → Phase 10 的依赖顺序推进。
   - 每项任务完成后必须在此勾选 `[x]`，且必须同时具备 **「代码实现 + 强类型状态机 + 单元/集成测试 + 截图/平台验证证据」**。

### Phase 09：数据多端同步、漫游与密码学凭据安全 (Sync, Roaming & Crypto Vault)

- [x] **T09-02 [P1] 配置版本向量时钟 (Vector Clock) 追踪**：为每份配置文件引入版本代数（Generation）与修改设备 ID，精准判断修改先后。
- [x] **T09-03 [P1] 配置冲突三向可视化合并 (3-Way Merge)**：发生冲突时，UI 直观呈现 Local / Remote / Base 三列差异，支持逐字段勾选合并。
- [x] **T09-04 [P0] 敏感凭据全面收敛至 OS Keyring**：WebDAV 密码、订阅 Token 100% 存入 Windows Credential Manager / macOS Keychain / Linux Secret Service。
- [x] **T09-05 [P1] 本地配置备份与密码加密导出**：支持将所有 Profiles、Mixin 与 Settings 导出为一个带 AES256-GCM 密码保护的备份包。
- [x] **T09-06 [P2] 局域网设备间一键扫码加密快传 (P2P)**：桌面端生成一次性二维码/配对码，手机端扫码通过局域网 TLS 直连秒级同步配置。
- [x] **T09-07 [P2] 多设备漫游同步策略偏好定制**：支持自由选择同步范围（如“仅同步订阅链接”、“仅同步自定义规则”、“全量同步”）。
- [x] **T09-08 [P1] WebDAV 同步失败智能退避与重试**：遭遇网络超时或 503 限流时，自动按指数退避算法（1m, 2m, 5m, 15m）重试。
- [x] **T09-09 [P2] 同步操作审计日志与追溯**：记录每次同步的详细日志（上传/下载条目数、冲突数、耗时），支持在 UI 查阅历史。
- [x] **T09-10 [P3] 移动端 iCloud / Google Drive 备份扩展**：为 iOS / Android 预留原生云盘备份扩展接口，支持一键备份到移动端专属私有云。
